Flexible Deployment

Three Modes for Any Development Setup

Run standalone on your primary workstation, or distribute across laptops, build servers, and cloud development instances.

Default

Local Mode

Everything runs within a single desktop widget. Scans local coding tools, watches logs, and renders stats with zero external network dependencies.

  • 100% offline & private
  • Tray & floating HUD support
  • Zero network setup required
Remote Fleet

Client Sync Mode

Runs on headless development servers or secondary machines. Gathers local metrics and securely posts wire records to your designated Hub.

  • Headless daemon (npm run agent)
  • Automatic backoff with widget PID
  • Stale device auto-detection
Central Hub

Host Server Mode

Runs a lightweight Node HTTP server. Ingests usage records across your devices and serves a unified fleet overview over SSE streaming.

  • Built-in or standalone hub (npm run hub)
  • Real-time Server-Sent Events (SSE)
  • Multi-device aggregated totals
Zero Telemetry

Engineered for Strict Security and Privacy

Your source code, prompts, and credentials never touch our servers. Token Orchestrator is completely self-contained.

POSIX 0600 Plaintext Store

API credentials are saved locally in credentials.json with strict filesystem permissions (0600 on Unix, ACL restricted on Windows).

Default-Deny GUI Redaction

The Electron main process strips raw credentials before sending configuration states to the renderer window.

Code Signed via SignPath

Official Windows executables and installers are Authenticode-signed by the SignPath Foundation for tamper-proof integrity.

No Cloud Analytics or Tracking

Zero third-party trackers, zero telemetry beacons, and zero prompt logging. You own 100% of your usage data.
